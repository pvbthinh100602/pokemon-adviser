# Data

- `trainers_4_1_normal_mingrind.txt`: Radical Red v4.1 trainer sets for **Normal mode, Minimal Grinding** (the mode Thinh plays), in Showdown format so sets can be pasted into a damage calculator. Source: Rudo2204's public gist (https://gist.github.com/Rudo2204/f4a06a37c2320e2b6094958e8dad785c), based on luckytyphlosion's dump. Known caveat from the author: "Level: Max Level" checks are not 100% accurate, especially for bosses; check the official docs for level caps.
- Find a trainer with a search such as `Leader Brock`, `Leader Misty`, or the trainer id from the logger's `battle_start`/`battle_end` events (`trainer_id` 414 = `0x19e` = Brock).

- `raid_encounters.json`: Max Raid / Dynamax den encounter table decoded from the player's Radical Red v4.1 ROM (CFRU `gRaidsByMapSection` at ROM offset 0x1134C34). For each map section and star tier it lists species (with form labels such as Meowth-Galar), types, raid ability slot, and item drops with rates. It also includes the badge-to-star mapping and per-star level ranges. The ROM itself is not in this repository. Regenerate with `python logger/dev-test/dump_raid_tables.py <rom.gba> --json data/raid_encounters.json`. Some dens reuse the same species list for every star tier; the battle level still follows the star range. With 1 gym badge only 1-star raids can appear (level 20-25).
